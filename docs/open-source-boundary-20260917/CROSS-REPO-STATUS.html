6. 本地 worktree 治理建议

问题：用一个 worktree 治理 skill 管理本地分支，合并导致部分内容未同步。
  • 每 task 分支独立 worktree：git worktree add ../wt-<branch> <branch>，不要在多 task 分支间切换同一个受管 worktree。
  • 合并前同步校验：merge/rebase 进 test/main 前先 git fetch --all --prune 并验证 git diff <base>...HEAD 的 tree 相等；未跟踪的 song-specific 产物（runs/、samples/）不得留在共享 worktree。
  • pre-merge 闸门：工作树存在 allowlist 外的未跟踪文件时合并失败，避免漏同步/静默覆盖（本次分析即因本地 2 处 wind-dream 修改需 stash 才切分支）。
  • 受管 worktree 仅承载单一 task；跨 task 内容用 workbench-private 远端回拉，而非本地拷贝。
